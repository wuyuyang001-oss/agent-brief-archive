今日论文

Delivery, Not Storage: Cue-Anchored Working Memory as a Harness Property for Coding Agents

作者：Swapnanil Saha
发布日期：2026-07-23
链接：arXiv · 官方 HTML · 未在论文公开页发现可核验的代码仓库

此前遇到的问题长程 coding agent 把记忆当成“可选择写入、可选择查找”的文档；一旦模型忘记调用记忆工具，存储再完整也无法在需要时进入上下文。
研究做法把记忆触发器做成 harness 的确定性能力：每条记忆绑定 path、symbol、semantic、event、temporal 等 cue，由运行时判断并主动注入。
关键结论预置的自愿记忆在 114 turns 中被调用 0 次；确定性注入在所有 seeded runs 中送达且无误报。会话内 39% 的重复读取是在重新购买压缩前已读内容；10 条事实经 harness 注入穿过 138/138 次 compact-resume。
与既有工作的差异与“模型主动写/查 memory”不同，可靠性责任从策略转移到运行时；记忆的产品形态从数据库变成可审计的投递协议。
可信度中低。机制日志细，结果方向明确，但直接对照仅少量运行、单一真实代码任务、单作者、同一模型与 harness；效率汇总未达到统计显著。
局限不能证明 cue 设计能跨仓库泛化；误触发、过度注入、隐私与权限边界尚未在多人生产环境验证；没有独立复现。
后续进展 / 待验证把“忘记查记忆率、错误注入率、重复读取 token、压缩后事实召回”加入 coding-agent harness 评测。
展开英文简介与逐段中文翻译

English overview

Coding agents usually treat memory as documents that the model must deliberately write and retrieve. This paper argues that situational operational facts should instead be delivered by the harness when path, symbol, semantic, event, or temporal cues fire. In a real coding task, voluntary memory use was zero across 114 turns, deterministic injection reached every seeded run without false alarms, and repeated-compaction probes preserved ten injected facts across 138 compact-resumes. The evidence is suggestive rather than definitive because the direct comparison is small and concentrated on one task and one model.

对应中文翻译

Coding Agent 通常把记忆当成需要模型主动写入和检索的文档。论文主张，路径、符号、语义、事件或时间 cue 出现时，应由 harness 主动投递情境性操作事实。在一个真实编码任务中，自愿记忆在 114 turns 内零调用，确定性注入覆盖全部 seeded runs 且无误报；重复压缩实验中，10 条注入事实穿过 138 次 compact-resume。由于直接比较样本小、集中在单一任务和模型，这些证据更适合作为架构假设而非最终结论。

本周最重要的 7 个信号
  1. 多 Agent 只有在信息瓶颈能去噪而不丢任务信息时才有稳定收益。
  2. 失败轨迹能把原问题转成更容易诊断的恢复任务，恢复路由应独立于初始模型路由。
  3. 评测器要随策略共同进化，否则 reward 迅速失去区分度。
  4. 完整日志 + 程序化检索是长程记忆的强基线，先于复杂向量记忆。
  5. 成本、pass@1、best@k 和交互预算必须联合报告。
  6. OpenAI 的科研与 Health 工作流说明高价值 Agent 产品会围绕连接器、权限和审计构建。
  7. 评测基础设施本身已成为安全边界，内部低拒绝模型和答案访问必须隔离。

模型能力

能力增益越来越依赖可用计算、检索和恢复策略；单次成功率不足以代表产品能力。

产品 / 创业假设

  1. “Harness-aware eval”会成为模型榜单之外的独立产品：同模型在不同 runtime 下的差异可直接指导采购。
  2. 面向高风险连接器的权限回放、撤销完整性与误外发评测可形成企业验收层。
  3. Agent 记忆的首个商业价值不是知识库，而是可审计的上下文投递与重复成本治理。

观点更新：“多 Agent 天然更强”被削弱；“runtime 是核心能力放大器”得到增强；“更长上下文能替代记忆系统”尚未被证实。下周关键问题是：harness 增益能否跨模型稳定复现，以及 evaluator 是否会因策略优化迅速失效。
