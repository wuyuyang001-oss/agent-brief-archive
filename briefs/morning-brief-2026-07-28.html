今日论文

Molt: A Scalable PyTorch-Native Training Framework for Agentic Reinforcement Learning

作者：Jian Hu, Huiying Li, Hao Zhang, Binfeng Xu, Yifan Zhang, Shaokun Zhang, Hemil Desai, Michael Demoret, Pavlo Molchanov, Jan Kautz, Yi Dong
发布日期：2026-07-22
链接：arXiv · 官方 HTML · 代码仓库

选择原因：上次截止后没有发现相关性与可验证性更高的新论文；该文虽于 7 月 22 日发布，但近期获得新的社区可见度，且开放代码、直接回答 Agent RL runtime 可修改性与一致性问题，因此选为今日最重要补充。

此前遇到的问题Agentic RL 框架的 trainer、并行后端、rollout 与胶水层高度耦合；改动会穿透整个栈，而且 token、策略版本或 forward 语义不一致时，训练可能在“看起来运行”的状态下失效。
研究做法以 PyTorch-native、可读性优先的代码组织三个组件和一个异步循环：普通 Python Agent、路由后的 vLLM rollout engines、FSDP2 policy actor，以及 Ray 异步队列。框架显式维护 token identity、policy-version semantics 与 forward consistency。
关键结论同一主循环支持多模态与 MoE，并从 4B dense 扩展到 700B MoE。匹配协议下，Molt 为 119.4±2.3 秒/step，slime 为 109.5±10.3 秒/step，作者认为吞吐统计上相近。
与既有工作的差异没有提出新 RL objective，而是用更小、可审计、适合人和 Coding Agent 修改的实现，把 rollout 到训练的 token 精确性与策略版本语义放在架构中心。
可信度架构透明度高：代码、recipe 与容器公开。性能/收敛可信度为中低：仅 3 次独立运行，训练 backend 与 rollout engine 仍有残余差异，关键基准因分布式 MoE forward 不一致而没有执行有效 policy update。
局限吞吐不能证明训练后质量或收敛 parity；多版本 serving、资源弹性、最优规划与用户可用性不在范围内；尚无独立复现。
后续进展 / 待验证修复并独立复现 MoE forward 一致性后，必须报告有效更新、奖励/KL 曲线、收敛质量、成本与故障恢复；还需验证“适合 Coding Agent 修改”的主张是否降低真实开发时间与回归率。
展开英文简介与逐段中文翻译

English overview

Molt is a PyTorch-native framework for agentic reinforcement learning designed around readability, token-exact data flow, and explicit policy-version semantics. It composes ordinary Python agents, vLLM rollout engines, a FSDP2 policy actor built with NeMo AutoModel, and a Ray asynchronous queue into one training loop. The same architecture supports multimodal and mixture-of-experts models and scales from 4B dense models to 700B MoE models.

The paper reports statistically comparable step-time throughput to a recommended slime/Megatron configuration under a matched workload. That result must be interpreted narrowly: a distributed-MoE forward mismatch caused the benchmark batch to be rejected by Molt's consistency gate, so the measurements characterize system throughput without an effective policy update. The work therefore provides strong architectural transparency but not yet convergence or final-policy parity.

对应中文翻译

Molt 是一个 PyTorch-native 的 Agentic RL 框架，围绕可读性、token 精确数据流与显式策略版本语义设计。它把普通 Python Agent、vLLM rollout engine、由 NeMo AutoModel 构建的 FSDP2 policy actor，以及 Ray 异步队列组合为一个训练循环。同一架构支持多模态与混合专家模型，并可从 4B dense 扩展到 700B MoE。

论文在匹配工作负载下报告了与推荐 slime/Megatron 配置统计上相近的 step-time 吞吐。但该结果必须窄化解读：分布式 MoE forward 不一致触发了 Molt 的一致性 gate，基准 batch 被拒绝，因此测量描述的是没有有效策略更新时的系统吞吐。该工作提供了较强的架构透明度，但尚未证明收敛或最终策略质量相当。
