今日论文

Messier: A High-Resolution Corpus for Cross-Benchmark Agent Evaluation

作者：Stefan Krsteski, Charlotte Meyer, Guillaume Allegre, Tony O’Halloran, Alexandre Sallinen
发布日期：2026-07-28
选择原因：它不是上次截止后新提交的论文，但昨天的一篇额度用于 HANDBOOK；Messier 是近期尚未总结、最直接服务跨 benchmark 评测产品的数据基础设施论文。
链接：arXiv · 官方 HTML · 匿名代码 / 样例项目页

此前遇到的问题Agent benchmark 的结果散落在论文表格、榜单、CSV 与轨迹中，模型、scaffold、环境、验证器和聚合口径混在一起，跨榜单比较容易把评分规则差异误当成能力差异。
研究做法规范化 24 个公开发布，并在 6 个专业/科学 benchmark 上补充 5 个 Agent 的统一运行，得到 957,253 个 trial、30 个 benchmark、714 个 Agent、11,891 个任务、74,205 个 verifier 和 5,360 个环境；同时保存聚合规则、行业标签和来源血缘。
关键结论函数调用趋于饱和，编程改善最快，企业工作流最难；all-pass 会抹去部分进展并在部分 benchmark 中改变 Agent 排名；Messier 拟合能力与 Epoch ECI 的排序相关为 Spearman ρ=0.81。
与既有工作的差异重点不是再造一个单榜，而是构建可重算的跨 benchmark trial corpus。相较只保存总分，它把 Agent 拆为 model + scaffold，并把 task、environment、verifier 和 aggregation rule 作为一等实体。
可信度中等：规模大、schema 与归一化方法公开、部分补跑使用统一网格，且有 ECI 外部排序对照；但来源异构、部分元数据由作者推断，完整轨迹并非普遍可得，尚无独立复现。
局限上游 benchmark 质量和发布偏差会被一并继承；补充实验只覆盖 5 个 Agent / 6 个 benchmark；反事实聚合不能恢复缺失运行；行业映射与任务难度预测存在主观和统计不确定性；匿名项目页降低长期可追踪性。
后续进展 / 待验证发布稳定版本与完整数据血缘；对关键控制引入 verifier severity；在相同 trial 上比较 strict、soft、near-pass 与真实业务损失；验证跨 benchmark 能力尺度能否预测线上成功、成本和副作用。
展开英文简介与逐段中文翻译

English overview

Messier addresses a measurement problem in agent evaluation: benchmark results are distributed across papers, leaderboards, CSV files, and trajectories, while model, scaffold, environment, verifier, and score aggregation are often conflated. The authors normalize 24 public releases and add a uniform five-agent evaluation grid on six underrepresented professional and scientific benchmarks. The resulting corpus contains 957,253 trials across 30 benchmarks and 714 distinct agents, with provenance and aggregation rules represented explicitly.

Cross-benchmark analysis suggests that function calling is approaching saturation, programming capability is improving fastest, and enterprise workflows remain the hardest group. Counterfactual rescoring shows that all-pass aggregation can hide partial progress and sometimes reorder agents, while a one-parameter IRT capability scale aligns with Epoch's ECI ordering at Spearman rho 0.81. These findings make Messier useful as evaluation infrastructure, but not a universal product-quality score: upstream benchmarks are heterogeneous, trajectory coverage is incomplete, metadata is sometimes inferred, and the new evaluation grid covers only five agents on six benchmarks.

对应中文翻译

Messier 处理的是 Agent 评测中的测量问题：benchmark 结果分散在论文、榜单、CSV 和轨迹中，而模型、scaffold、环境、验证器和分数聚合经常混为一谈。作者规范化了 24 个公开发布，并在 6 个覆盖不足的专业与科学 benchmark 上增加统一的五 Agent 评测网格。最终语料包含 30 个 benchmark、714 个不同 Agent 的 957,253 次 trial，并显式表示来源血缘和聚合规则。

跨 benchmark 分析表明，函数调用正在趋于饱和，编程能力改善最快，企业工作流仍是最难的一组。反事实重算显示，all-pass 聚合会隐藏部分进展并有时改变 Agent 排名；单参数 IRT 能力尺度与 Epoch ECI 排序的 Spearman 相关达到 0.81。这使 Messier 适合作为评测基础设施，但不能直接充当通用产品质量分：上游 benchmark 异构、轨迹覆盖不完整、部分元数据由推断得到，新补充的评测网格也只覆盖 5 个 Agent 和 6 个 benchmark。
