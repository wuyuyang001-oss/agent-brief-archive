Agent Skill 评测要记录首次失败，而不是奖励事后修补

评测方法 / 新出现
核心结论
AEVAL 将执行器与评分器分离，只评首次轨迹并预先写断言，避免同一 Agent 修补技能后把被纠正的结果当成原始通过。

今日论文

AEVAL: From Anecdotal to Deterministic Testing for Agentic Skill Workflows

作者：Tejas Singh Anand, Yuet Ying Christina Wang, Wanting Jiang, Steve Masson, Tian Zheng, Bingjie Zhou
发布日期：2026-07-16；修订：2026-07-21 · ICML 2026 Workshop
链接：arXiv · HTML · 代码 / 项目页：未发现公开链接
选择原因：自 8 月 3 日最近一次成功报告后未发现同等重要的新论文；该文此前未总结，且直接对应 Agent Skill、评测产品与可复用 CI 合同。

此前遇到的问题技能测试多靠演示与最终结果；同一 Agent 执行、遇错、修改技能，再对修正后状态打分，产生 self-correction bias。
研究做法每个 Skill 携带 eval.config；变更触发 CI。执行器跑四阶段工作流，独立评分器只看提示、首试轨迹、输出与预先生成的断言，不接触修正后状态。
关键结论故障注入案例中，朴素评测修补 action name 后给出 100%；AEVAL 仍记录 3 个首试错误、2 次修改，并让相关断言失败。6 次双后端运行显示总通过率接近，但因果级建议占比与协议保真明显不同。
与既有工作的差异把“最终任务完成”拆成“首次技能可靠性、Agent 自我修正、协议保真和环境故障”，并将修复建议分为 merge-blocking LV1 与 advisory LV2。
可信度中等偏低：来自真实技能市场，并给出故障注入与 matched runs；但跨后端仅 6 次，断言列表由各评分器生成且分母不同，无公开代码、轨迹、置信区间或独立复现。
局限多数结论仍是定性；首试因果归因可能出错，模拟输出禁令主要靠指令；协议模板与 LV1/LV2 边界含主观性，计算随后端数量线性增长。
后续进展 / 待验证需要固定共享断言集、公开轨迹、盲评与重复运行；检验真实环境漂移、恶意 Skill、grader 偏差，以及首次成功率是否预测生产事故。
展开英文简介与逐段中文翻译

English overview

Agentic skills are often tested through demonstrations that reward the final corrected outcome. When the same agent executes a workflow, silently patches the skill after an error, and then grades the repaired state, a broken first attempt can be reported as a pass. AEVAL turns each skill into a CI-tested contract: an eval.config declares the prompt, expected outcome, and credentials, while a separate grader writes assertions before seeing outputs and evaluates only the first-attempt transcript and artifacts.

The paper demonstrates the method with a production skill marketplace, an intentionally degraded segmentation skill, and six matched runs across two agent backends. AEVAL exposes errors hidden by naive evaluation and separates merge-blocking causal suggestions from advisory improvements. The evidence is promising but preliminary: the quantitative sample is small, assertion sets differ by grader, code and trajectories are not public, and there is no independent replication.

对应中文翻译

Agent Skill 常通过演示测试，并奖励最终修正后的结果。如果同一个 Agent 执行工作流、出错后悄悄修改 Skill，再对修复后的状态评分，首次执行明明损坏也可能被报告为通过。AEVAL 把每个 Skill 变成由 CI 测试的合同：eval.config 声明提示、期望结果和凭据；独立评分器在看到输出前写断言，并且只评首试轨迹与产物。

论文用真实技能市场、一个被故意破坏的分群 Skill，以及两个 Agent 后端的 6 次 matched runs 展示方法。AEVAL 能暴露朴素评测掩盖的错误，并将 merge-blocking 因果建议与 advisory 改进分开。证据有启发性但仍属初步：定量样本很小、不同评分器的断言集合不同、代码与轨迹未公开，也没有独立复现。
