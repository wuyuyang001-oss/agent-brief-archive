已证实：Agent 的难点从“做对一次”转向“环境变了还能修复”

新论文 / 证据增强
核心结论
8 月 14 日的 PACE-Bench 让原本能工作的代码面对同接口、不同物理条件的目标环境；十种自进化方法尚未饱和，反思配合模拟器反馈优于未经核验的自我修改。
证据 / 可信度
144 个源→目标适应对、6 个物理领域、10 种方法；作者报告 Reflexion + Qwen3-14B 全集 Pass@2 为 35.9%，GPT-5.5 在静力子集、完整预算下为 66.7%。有代码与数据，但为作者自报、尚无独立复现。
与既有工作的差异
不是固定环境里的解题或跨任务迁移，而是测试已执行设计在环境变更后的诊断、重构与恢复。
产品 / 评测意义
评测产品应加入“变更后恢复”轨迹：检查点、诊断证据、尝试预算、回滚代价和不可逆副作用，而不只报首轮成功率。
建议动作
把一个真实工作流的依赖、数据格式或权限规则做受控变更；记录 Agent 是否定位机制、重做方案并安全恢复。

今日论文

PACE-Bench: Benchmarking Physics Adaptation via Code Evolution in Dynamic Environments

作者：Yuhao Zhan、Bingxiang He、Zecong Tang、Chaojun Xiao
发布日期：2026-08-14 16:25 UTC
链接：arXiv · HTML · 代码与数据

此前遇到的问题自进化 Agent 的评测通常固定执行条件，难以衡量环境发生变化后是否能从失败中恢复，而非只在原任务上反复优化。
研究做法构建 144 个源→目标适应对，覆盖 6 类物理任务。源环境中的代码在目标环境失效，Agent 在受限尝试预算内使用诊断沙箱反馈调整可执行设计；比较 4 类范式的 10 种方法。
关键结论模拟器支撑的反思比未经验证的自我修订可靠；记忆容易锚定早期设计，宽树搜索会探索但难以收敛。即使披露准确物理变更，性能上限也未提高，瓶颈是机制重构而非参数猜测。
与既有工作的差异评测的是同目标、同接口下的环境漂移恢复，不是新任务泛化；产物是能否重写并重新运行的代码，而不是只评文本答案。
可信度中等：任务数、领域和方法对比清晰，附代码/数据和 20 次尝试预算分析；但作者自报、仅模拟物理领域，完整榜单以 Pass@2 为主，成本、真实生产变更和独立复现仍待验证。
局限物理模拟器的诊断信号比真实 SaaS、网页和企业数据环境更干净；源/目标变更设计可能被测试集适配；没有直接量化不可逆副作用、权限变化或跨服务状态恢复。
后续待验证问题将同样协议迁移到 API 版本变更、数据模式漂移和权限收紧；报告每次恢复的成本、失败分类、回滚是否完整，并按真实业务错误成本加权。
展开英文简介与逐段对应中文翻译

English overview

PACE-Bench evaluates whether self-evolving agents can adapt executable designs after an environment changes while the task goal and interface remain fixed. It contains 144 source-to-target pairs across six physics domains and evaluates ten methods with diagnostic sandbox feedback under limited attempt budgets.

The reported results remain far from saturation. Simulator-grounded reflection is more reliable than unverified self-revision, while memory can anchor agents to early designs and broad tree search may explore without converging. The benchmark is useful evidence for recovery-oriented evaluation, but its simulator setting and author-reported results require independent validation before transfer to production agents.

对应中文翻译

PACE-Bench 评测自进化 Agent：当任务目标和接口不变、环境发生变化时，它能否适应可执行设计。数据集包含 6 个物理领域的 144 个源→目标对；方法在受限尝试预算内利用诊断沙箱反馈。

作者报告的结果远未饱和。以模拟器为依据的反思比未经验证的自我修订更可靠；记忆可能把 Agent 锚在早期设计，宽树搜索虽会探索但未必收敛。该工作为恢复导向评测提供证据，但在迁移到生产 Agent 前仍需要独立验证其模拟器设定与作者自报结果。
