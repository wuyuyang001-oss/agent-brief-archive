今日论文

PACE-Bench: Benchmarking Physics Adaptation via Code Evolution in Dynamic Environments

作者：Yuhao Zhan、Bingxiang He、Zecong Tang、Chaojun Xiao
发布日期：2026-08-14 16:25 UTC
链接：arXiv · HTML · 代码与数据（GitHub 快照：1 Star，MIT，2026-08-17T03:05:31Z）

此前遇到的问题已有自我进化 Agent 评测多在固定执行条件下优化或做一般迁移，未检验同一可执行设计在环境机制变化后能否发现问题、重设计并恢复。
研究做法构造 6 个物理领域、36 个任务、144 个源环境→目标环境配对；目标环境保持目标与接口但改变物理参数。比较 10 种自我进化方法、四类范式，以模拟器反馈、Pass@2 与 Score@2 评价。
关键结论最强完整配置 Reflexion + Qwen3-14B 仅达 35.9% Pass@2；显式、经模拟器验证的失败分析优于未验证自改写。披露精确变化参数也没有提高总体性能上限，重设计机制比识别参数更难。
与既有工作的差异把动态适应而非静态优化作为目标，并直接检验记忆、搜索、反思和参数型方法在环境漂移下的失败模式。
可信度中等：任务与反馈可执行、公开代码/数据、比较面广、两次独立运行；但有效分母因生成/运行失败会缩小，固定 20 次尝试，且前沿模型和辅助设置的覆盖不完整，尚无独立复现。
局限仅受控 2D Box2D，不能直接外推 3D、真实机器人、噪声感知/执行或更长的生产任务；没有真实用户、权限与不可逆副作用。
后续进展 / 待验证问题需在真实工具 API 漂移、长时状态恢复和生产变更上测试；评价应同时报告恢复率、时间/成本、错误类型和安全回滚，而不只报成功率。
展开英文简介与逐段对应中文翻译

English overview

PACE-Bench evaluates whether self-evolving agents can adapt executable designs after their environment changes. It contains 144 source-to-target pairs across six physics domains. A source design that works is transferred to a target with the same goal and interface but mutated physical conditions; the agent receives diagnostic simulator feedback and has a limited attempt budget to revise the design.

Across ten methods, verified simulator-grounded reflection is more reliable than unverified self-revision, while memory can anchor agents to obsolete designs and broad search can fail to converge. The benchmark remains unsaturated: the strongest reported full configuration reaches 35.9% Pass@2. The controlled 2D simulator and fixed budget are important limits on real-world generalization.

对应中文翻译

PACE-Bench 评估自我进化 Agent 在环境改变后，能否适应可执行设计。它包含 6 个物理领域的 144 个源环境→目标环境对：源设计原本可行，目标保持相同目标与接口但改变物理条件；Agent 通过诊断性模拟器反馈，在有限尝试预算内修订设计。

在 10 种方法的对比中，经过模拟器验证的反思比未验证的自我改写更可靠；记忆可能把 Agent 锚定在已过时的设计上，广搜索可能不能收敛。最强报告配置也仅有 35.9% Pass@2。受控 2D 模拟器和固定预算限制了向真实世界的外推。
