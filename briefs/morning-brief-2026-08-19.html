产品 / 评测意义
产品护城河可能位于领域规范、完整性检查和产物验证，而不只是模型调用；“进程成功”不能替代“交付物通过”。
建议动作
把核心用户任务写成加权验收清单；独立打开最终文件做结构、数值和格式复核，并记录最严重失败项。

Agent 产品
核心结论
通用 Agent 平均分 64.26、成功率 19.74%；专用 Agent 为 83.50 和 39.18%。差距集中在复杂指令、领域知识、专业惯例和长程执行。
证据 / 可信度
来自同一论文的统一评测；专用产品的底层模型、工具和工程投入未必完全同质，不能把全部差距归因于“架构”。
与既有工作的差异
不是比较单步工具调用，而是比较用户最终愿意付费的完整工作流。
产品 / 评测意义
创业机会更接近“通用模型 + 垂直知识 + 可验证产物 + 工作流治理”，而不是另做一个聊天壳。
建议动作
选一个高价值垂直任务，先做专用验收器与回归集，再决定是否需要专用 Agent 编排。

今日论文

StartupBench: Benchmarking General-Purpose Agents on Market-Validated End-to-End Workflows

作者：Liya Zhu、Xin Ma、Tao Liu 等
发布日期：2026-08-18 14:01 UTC
链接：arXiv · HTML · 项目页

此前遇到的问题现有 Agent benchmark 多由研究者选择任务，难以证明高分对应真实用户需求；整体 judge 也容易忽略最终交付物里的关键错误。
研究做法从已有采用的 AI 创业产品、产品演示与用户访谈提取工作流，构建 97 个跨 6 领域的端到端任务；57 位专家参与构建和交叉验证，用 2,453 条 rubric 检查正确性、完整性、数据处理、专业推理、工程质量和呈现。
关键结论最强通用模型即使取三次运行中的最好结果，成功率也约 28.06%；普通汇总下通用系统成功率 19.74%，专用系统 39.18%。Agent 常做出大量部分进展，却无法产出可直接使用的交付物。
与既有工作的差异以市场验证工作流而非研究者假设为任务源；要求完整文件产物；用逐项加权验收条件而非单一整体评分，并分析“自我验证幻觉”。
可信度中等：任务和 rubric 规模可观、专家背景透明、统一 harness 且每项三次运行；但刚发布，未见独立复现，项目页公开程度和全部原始轨迹仍需持续核验。Agent-as-a-judge 仍可能带入模型偏差。
局限创业产品有选择偏差；市场采用不等于任务代表性；专用与通用系统未必在模型、工具和预算上完全公平；成功阈值设为得分 ≥90，阈值敏感性需进一步验证；静态任务不能覆盖部署中的交互和责任风险。
后续待验证问题公开任务、轨迹与 judge 后能否复现；不同成本预算下差距是否保持；artifact verifier 能否降低核心 rubric 失败；通用模型升级后，专用系统优势来自知识、工具还是工作流约束。
展开英文简介与逐段对应中文翻译

English overview

StartupBench evaluates general-purpose agents on end-to-end workflows derived from AI products with demonstrated adoption. The benchmark contains 97 tasks across six professional domains and uses 2,453 fine-grained rubric items to inspect complete deliverables rather than only intermediate text or coarse holistic judgments.

The strongest general-purpose setup completes only about 30% of tasks even under an oracle that keeps the best of three attempts. Specialized systems remain ahead, while failure analysis points to complex instruction following, domain expertise, professional conventions, long-horizon execution, and a recurring self-verification error: agents mistake a successful process summary for evidence that the final artifact is correct.

对应中文翻译

StartupBench 评测通用 Agent 完成源自已有用户采用 AI 产品的端到端工作流。它包含 6 个专业领域的 97 个任务，并以 2,453 条细粒度 rubric 检查完整交付物，而不只评中间文本或做粗粒度整体判断。

即使采用“每项三次取最好”的 oracle，最强通用方案也只完成约 30% 的任务，专用系统仍领先。失败集中在复杂指令遵循、领域知识、专业惯例和长程执行；还反复出现自我验证错误：Agent 把成功的过程摘要误当作最终产物正确的证据。
