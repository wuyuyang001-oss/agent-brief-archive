作者结论：成功不等于可用，最快 Agent 仍比人类慢 3.7 倍

Agent 产品边界
核心结论
强 Agent 能最终完成不少组件任务，但即使最快配置也耗时为匹配人类参考的 3.7 倍；滑块、拖拽列表和分割器等人类 1–2 步完成的操作，跨 Agent 平均成功率仍低于 60%。
证据 / 可信度
所有任务有清洗后的人类参考轨迹；额外 2 位标注者在 278 任务子集验证，人类间动作数差仅约 1.05 倍。
与既有工作的差异
除了 pass rate，还测是否在人类动作预算内完成，把延迟、成本和漂移风险纳入可用性。
产品 / 评测意义
纯视觉 Agent 的产品瓶颈不只在规划，而在高频 GUI 原语的可靠度与效率；组件级失败会在长流程中乘法累积。
建议动作
为高频组件建立回归门槛；低于 99% 的关键原语优先改为 API、DOM 或受控专用工具。

今日论文

ComponentBench: Diagnosing Component-Level Failures in Computer-Use Agents

作者：Tianchen Guan、Xinlei Lin、Royce Cheng-Yue、Xiangjun Wang、Shuyan Zhou
发布日期：2026-08-18（在上次简报截止后进入 arXiv cs.AI recent 列表）
链接：arXiv · HTML · 项目页 · 代码 · 数据与运行记录

此前遇到的问题长程 GUI benchmark 能测最终完成却难定位根因；单步 grounding benchmark 只测点哪里，覆盖不了日期选择、拖拽、滑块、组合筛选等短多步组件交互。
研究做法构建与 UI 库无关的 97 类组件本体、14 个交互族和 24 个模板，在 Ant Design、MUI、Mantine 等环境实例化 2,910 个程序化验证任务；配套人类轨迹、难度审计和轨迹级失败分类。
关键结论接口设计可令同一模型成功率变化超过 30 个百分点；最快配置仍比人类参考慢 3.7 倍；拖拽、滑块和 splitter 等空间操作跨 Agent 平均低于 60%；拥挤和紧凑间距尤其伤害视觉 Agent。
与既有工作的差异在真实长流程和原子定位之间增加可归因的组件层，既保留现代 UI 负担，又能程序化判定结果、比较动作效率并追踪具体失败机制。
可信度中等偏高：任务量大、状态验证程序化、任务级 bootstrap CI、代码/数据/运行公开；278 任务子集增加两名人类标注者和两次模型运行。局限是主表多数 model-mode cell 仅一次确定性运行。
局限主要是合成组件页面而非真实产品；任务聚焦单一主组件，弱化长程规划与跨页面状态；Browser-Use 的一步可含最多 4 个原子动作，效率口径偏乐观；UI-TARS 与 Opus 使用原生 harness，跨模型公平性不完全一致；尚无独立复现。
后续待验证问题组件得分能否预测真实网站成功率；把 Agent-ready 组件规范加入设计系统能否提升纯视觉可靠性；重复运行的任务级 churn 如何进入发布门槛；API/DOM fallback 的成本与安全收益。
展开英文简介与逐段对应中文翻译

English overview

ComponentBench fills the diagnostic gap between long-horizon workflow benchmarks and atomic grounding tests. It instantiates 97 canonical UI component types as 2,910 programmatically verified tasks, with cleaned human reference trajectories for measuring both completion and interaction efficiency.

Across seven models and four observation/action spaces, interface design changes performance dramatically: GPT-5 mini drops from 83.1% with accessibility-tree observations to 48.9% under coordinate-only Pixel control. Even the fastest agent configuration is 3.7 times slower than the matched human reference, while spatial manipulations remain persistent failure points.

对应中文翻译

ComponentBench 填补了长程工作流 benchmark 与原子 grounding 测试之间的诊断空白。它把 97 类标准 UI 组件实例化为 2,910 个程序化验证任务，并提供清洗后的人类参考轨迹，同时测完成率与交互效率。

在 7 个模型和 4 种观察/动作空间中，接口设计显著改变结果：GPT-5 mini 从可访问树观察的 83.1% 降至纯坐标 Pixel 控制的 48.9%。即使最快 Agent 配置也比匹配的人类参考慢 3.7 倍，空间操作仍是持续失败点。
